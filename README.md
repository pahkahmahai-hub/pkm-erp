### 1) Supabase — สร้างฐานข้อมูล
1. เปิดโปรเจกต์ `pkm-erp` ใน Supabase → **SQL Editor** → New query
2. รันไฟล์ใน `supabase/migrations/` **ตามลำดับ ทีละไฟล์** (คัดลอกทั้งไฟล์ วาง กด Run):
   - `0001_foundation_hr.sql` — ตารางทั้งหมดของรากฐาน + HR, สิทธิ์ (RLS), ข้อมูลตั้งต้น: 2 ทีม, พนักงาน 6 คน, admin 2 บัญชี, พิกัดโชว์รูม, เวลางาน, โควต้าลา
   - `0002_stock.sql` — โมดูลคลังใหญ่ + สมุดรายชื่อ + ที่เก็บรูป (storage bucket `stock-images`) + สินค้า 189 รายการ / รายชื่อ 452 ราย พร้อมยอดยกมา
   - `0003_defects_manual.sql` — บันทึก/ลบของเสียย้อนหลัง
   - `0004_attendance_requests.sql` — คำขอแก้เวลาเข้า-ออก (ลืมเช็คอิน/เช็คเอาท์)
   - `0005_work.sql` — โมดูลงาน: ห้องงาน 7 ห้อง (ตามกลุ่ม LINE) สั่งงาน เช็คลิสต์ คอมเมนต์+รูปแบบสด งานประจำ แจ้งเตือน
   - `0006_room_chat.sql` — แชทประจำห้อง (realtime) + ตัวนับยังไม่อ่าน + แปลงข้อความเป็นงาน
   - `0007_sales.sql`, `0008_contact_discount.sql` (GP%/ส่วนลดประจำลูกค้า), `0009_expenses.sql` (ค่าใช้จ่าย/เจ้าหนี้/หัก ณ ที่จ่าย), `0010_wht_standalone.sql` (50 ทวิ เลขที่แบบ FlowAccount WT+YYYYMM+ลำดับ, ออกใบเดี่ยว), `0011_intercompany.sql` (ยอดขายออนไลน์รายสินค้า, ใบเบิกซื้อ TKS→PKM ปิดเดือน, เลขที่เอกสาร TKS แบบ RC6910-0001), `0012_purchasing.sql` (จัดซื้อ: PR → อนุมัติ → PO → รับของเข้าคลัง → บิลค่าใช้จ่าย), `0013_production.sql` (การผลิต: BOM, ใบสั่งผลิต, เบิกวัสดุตัดสต็อก, รับสินค้า, ค่าจ้าง/ต้นทุน, วัสดุประเภทอุปกรณ์), `0014_team_rooms.sql` (GC ROOM / SW ROOM), `0015_chat_mentions.sql` (@mention ในแชท + แจ้งเตือน), `0016_store_deliveries.sql` (ตารางส่งสินค้าห้าง 7 ขั้นตอน, จัดการห้าง, สร้าง job), `0017_room_leads.sql` (หัวหน้าห้อง ★ โอน/แก้/ตรวจรับงานในห้อง), `0018_gc_calendar.sql` (ปฏิทินงานทีม, หัวข้อ Routine รายคน, storyboard หลายรูป, งานประจำรายเดือน/สัปดาห์แรก/วันเบิ้ล), `0019_review_rules.sql` (หัวหน้าห้องตรวจรับงานลูกทีม งานของตัวเองให้ผู้บริหารตรวจ), `0020_company_calendar.sql` (ปฏิทินบริษัท: ออกบูธ นัดหมาย ประชุมซ้ำ 5ส), `0021_holidays.sql` (วันหยุดประจำปี 2569–2570), `0022_signature_stamp.sql` (ลายเซ็น/ตราประทับบนเอกสาร, reply ในแชท), `0023_sw_delivery_stages.sql` (SW ROOM: เตรียมส่ง → ส่งแล้ว → ถึงแล้ว → เข้าระบบ) — โมดูลขาย: บริษัท 2 แห่ง (PKM จด VAT / TKS ไม่จด), เอกสารขายครบชุด เลขที่แบบ FlowAccount, ตัดสต็อกเมื่อออกใบส่งของ, ใบเสร็จตัดลูกหนี้, ยอดขายออนไลน์ 7 ช่องทาง
3. **Project Settings → API** จด `Project URL` และ `anon public` key

### 2) Google Sign-in
1. ไปที่ [Google Cloud Console](https://console.cloud.google.com/) → สร้าง project (หรือใช้ของเดิม) → **APIs & Services → Credentials → Create credentials → OAuth client ID** (Web application)
   - ถ้ายังไม่เคยตั้ง OAuth consent screen ให้ตั้งเป็น *External*, ใส่ชื่อแอป "PKM ERP" และอีเมลติดต่อ
   - **Authorized redirect URIs** ใส่: `https://<PROJECT-REF>.supabase.co/auth/v1/callback` (ดูค่าจริงได้ใน Supabase → Authentication → Providers → Google)
2. จด **Client ID** และ **Client Secret**
3. Supabase → **Authentication → Providers → Google** → เปิด Enable, วาง Client ID / Secret → Save
4. Supabase → **Authentication → URL Configuration**
   - Site URL: `https://pkm-erp.vercel.app` (หรือโดเมนจริงเมื่อมี)
   - Redirect URLs: เพิ่ม `https://pkm-erp.vercel.app/auth/callback` และ `http://localhost:3000/auth/callback`

### 3) Vercel — Deploy
1. [vercel.com](https://vercel.com) → **Add New → Project** → Import repo `pahkahmahai-hub/pkm-erp`
2. **Environment Variables** ใส่ 2 ค่า:
   - `NEXT_PUBLIC_SUPABASE_URL` = Project URL
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = anon key
3. Deploy → ได้ URL เช่น `https://pkm-erp.vercel.app`
4. กลับไปข้อ 2.4 ให้ Site URL / Redirect URL ตรงกับ URL ที่ได้

## โมดูลคลังใหญ่ — วิธีใช้สั้นๆ
- **รับเข้า**: เลือก/เพิ่มซัพพลายเออร์ → ใส่เลขใบส่งของ → เพิ่มสินค้าทีละบรรทัด (ยิงบาร์โค้ดได้) → แต่ละบรรทัดเลือก *ดี → เข้าคลัง* หรือ *เสีย → รอพิจารณา / รอส่งคืน* → บันทึก (ของดีเข้าสต็อกทันที ของเสียไปหน้า "ของเสีย")
- **ใบเบิก**: กรอกเอง หรือกด *อัปโหลด PDF จาก FlowAccount* (ใบส่งสินค้า/ใบกำกับ) ระบบอ่านเลขที่เอกสาร ลูกค้า และรายการ แล้วจับคู่สินค้าด้วยบาร์โค้ด → ตรวจ → บันทึก = ตัดสต็อก
- **ปรับยอด**: ในหน้าสินค้า ใส่ยอดใหม่ + เหตุผล ระบบเก็บชื่อผู้ปรับและผลต่าง
- **ของเสีย**: รอพิจารณา → รอส่งคืน → ส่งคืนแล้ว / ตัดทิ้ง / ใช้ได้ (กลับเข้าสต็อก)
- **ลายผ้า & แพคเกจจิ้ง**: เพิ่มรายการ อัปโหลดรูป รับเข้า/เบิกออก ดูคงเหลือ
- เลขที่เอกสาร: `RC-YYMM-NNN` (รับเข้า), `IS-YYMM-NNN` (ใบเบิก) ปี พ.ศ.
- FlowAccount Open API (ดึงเอกสารตรงไม่ต้องอัปโหลด PDF) — เตรียมช่องไว้แล้ว เพิ่มได้เมื่อมี API Key

## โมดูลขาย — วิธีใช้สั้นๆ
- เลือกบริษัทที่ออกเอกสาร (ปากาม้า = มี VAT, ทีฆาซอร์ส = ไม่มี VAT บังคับ) → ลูกค้าจากสมุดรายชื่อ → เพิ่มสินค้าจากคลัง (ราคาขายขึ้นเอง) หรือรายการอิสระ → เลือกโหมด VAT (รวม/ก่อน/ไม่มี) ส่วนลดท้ายบิล มัดจำ หัก ณ ที่จ่าย → **บันทึกร่าง** → ตรวจ → **ออกเอกสาร**
- ใบส่งของ/ใบกำกับ และใบส่งของชั่วคราว ที่ติ๊ก "ตัดสต็อก" จะสร้างใบเบิกคลังอัตโนมัติตอนออกเอกสาร
- ปุ่ม "สร้างเอกสารต่อ" คัดลอกรายการไปใบถัดไป (QT → INV → RE ฯลฯ) และอ้างอิงเลขที่ให้; ใบเสร็จที่สร้างจากใบส่งของจะตัดลูกหนี้เมื่อกด "รับเงินแล้ว"
- เลขที่: `QT/TD/INV/BL/RE/CN/DN` + ปี ค.ศ. + เดือน + ลำดับ 4 หลัก แยกชุดต่อบริษัท (กรอกเลขเองได้ตอนบันทึกเอกสารที่ออกจาก FlowAccount)
- พิมพ์: ปุ่ม "พิมพ์ / PDF" เปิดหน้าเอกสาร 2 หน้า (ต้นฉบับ/สำเนา) → Ctrl+P → Save as PDF
- ยอดขายออนไลน์: กรอกต่อวันต่อแพลตฟอร์ม (ออเดอร์ ยอด ค่าธรรมเนียม) ติ๊ก "เข้า TKS" เมื่อแพลตฟอร์มนั้นออกใบเสร็จในนามทีฆาซอร์สแล้ว

## กฎธุรกิจที่ฝังอยู่ในระบบ (แก้ได้ที่หน้าตั้งค่า)
- รหัสพนักงาน `PKM-YYTTNN` — YY = พ.ศ. 2 หลักของปีที่เข้า, TT = ทีม (01 SW, 02 GC), NN = ลำดับ — ระบบออกให้อัตโนมัติ
- เวลางาน 08:30–17:30 · ผ่อนผันสาย 15 นาที · วันทำงาน จ–ศ (เสาร์-อาทิตย์ไม่นับขาด)
- เช็คอินได้ทุกที่ แต่ถ้าห่างโชว์รูมเกิน 200 ม. จะติดสถานะ "นอกพื้นที่" ให้ admin เห็น
- ลา: ป่วย 30 / กิจ 6 / พักร้อน 6 วันต่อปี · ลาครึ่งวันได้ · admin 2 คนอนุมัติได้ทั้งคู่
- OT: พนักงานยื่นล่วงหน้าหรือย้อนหลังได้ admin อนุมัติและปรับชั่วโมงได้
- ขาด = วันทำงานที่ผ่านมาแล้ว ซึ่งไม่มีเช็คอินและไม่มีใบลาที่อนุมัติ
- สิทธิ์: พนักงานเห็นเฉพาะข้อมูลตัวเอง + รายชื่อเพื่อนร่วมงานแบบย่อ · ไม่เก็บเลขบัตรประชาชน
